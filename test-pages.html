🔧 前置条件

确保以下服务正在运行：

  1. 前端开发服务器：npm run dev:client (端口 5173)
  2. 后端 API 服务器：npm run dev:server (端口 8788)
  3. 或者直接运行：npm run dev

测试后端是否运行：

测试 API 端点 应返回 401 或数据

🐛 常见问题

  • 页面空白 → 检查是否添加了 active 类
  • 401 错误 → 需要先登录
  • 404 错误 → 后端服务器未启动
  • 加载中... → API 请求失败或超时
