# 修炼系统重构文档

## 概述
将修炼项目模块进行重大重构，使其与境界系统深度关联。每个境界都有专属的修炼项目，随着境界提升，修炼难度和奖励都会递增。

## 核心设计理念

### 1. 境界关联
- 每个境界至少有10个专属修炼项目
- 修炼项目按境界解锁，低境界无法修炼高境界功法
- 修炼项目的难度、消耗、奖励都随境界递增

### 2. 修炼分类
**按类型分类：**
- `basic` - 基础修炼：入门级，成功率高
- `advanced` - 高级修炼：进阶级，奖励更好
- `secret` - 秘法修炼：稀有功法，效果强大
- `forbidden` - 禁术修炼：危险但强大

**按类别分类：**
- `breathing` - 吐纳：呼吸法门
- `meditation` - 冥想：心法修炼
- `body` - 炼体：肉身强化
- `soul` - 炼魂：灵魂修炼
- `qi` - 炼气：真气修炼
- `breakthrough` - 突破：境界突破辅助

### 3. 修炼机制

#### 成功率计算
```
基础成功率 = 70%
难度惩罚 = 难度等级 × 3%
等级加成 = 用户等级 × 2%
最终成功率 = max(30%, min(95%, 基础成功率 - 难度惩罚 + 等级加成))
```

#### 暴击机制
- 成功修炼有10%概率触发暴击
- 暴击时奖励翻倍
- 失败时也能获得30%的奖励（经验和资源）

#### 等级系统
- 每个修炼项目都有独立的等级和经验
- 等级提升会增加成功率
- 达到满级后标记为"精通"

### 4. 限制机制
- **每日限制**：某些功法每天只能修炼有限次数
- **冷却时间**：修炼后需要等待冷却
- **激活限制**：最多同时激活5个功法
- **消耗限制**：需要足够的功德、寿命或复活币

## 数据库结构

### cultivation_practices（修炼项目配置表）
```sql
- id: 主键
- key: 唯一标识
- name: 功法名称
- emoji: 图标
- description: 描述
- realm_id: 所属境界
- required_realm_level: 需要的小境界等级
- practice_type: 修炼类型
- category: 修炼类别
- difficulty: 难度（1-10）
- practice_time: 修炼时间（秒）
- cooldown_time: 冷却时间（秒）
- cost_merit: 功德消耗
- cost_life: 寿命消耗
- cost_coin: 复活币消耗
- reward_life: 寿命奖励
- reward_merit: 功德奖励
- reward_shard: 碎片奖励
- reward_exp: 经验奖励
- effect_type: 效果类型
- effect_value: 效果数值
- effect_duration: 效果持续时间
- helps_breakthrough: 是否助力突破
- breakthrough_contribution: 突破贡献值
- max_level: 最大等级
- daily_limit: 每日限制
- prerequisite_practice: 前置要求
- rarity: 稀有度
```

### user_cultivation_progress（用户修炼进度表）
```sql
- id: 主键
- user_id: 用户ID
- practice_key: 功法标识
- level: 当前等级
- experience: 当前经验
- total_practice_count: 总修炼次数
- success_count: 成功次数
- failure_count: 失败次数
- first_practice_at: 首次修炼时间
- last_practice_at: 最后修炼时间
- last_success_at: 最后成功时间
- today_practice_count: 今日修炼次数
- today_date: 今日日期
- is_active: 是否激活
- is_mastered: 是否精通
- breakthrough_ready: 是否突破就绪
```

### cultivation_records（修炼记录表）
```sql
- id: 主键
- user_id: 用户ID
- practice_key: 功法标识
- practice_level: 修炼时等级
- result: 结果（success/failure/critical/breakthrough）
- cost_merit: 消耗功德
- cost_life: 消耗寿命
- reward_life: 获得寿命
- reward_merit: 获得功德
- reward_shard: 获得碎片
- reward_exp: 获得经验
- notes: 修炼心得
- created_at: 创建时间
```
