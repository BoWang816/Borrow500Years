# 扩展养生项目境界系统重构 - 完成总结

## 概述
将扩展养生项目（extra_tasks_config）与境界系统关联，不同境界有不同的养生项目，难度和收益与境界相对应。

## 完成时间
2026年5月14日

## 数据库变更

### 新增字段
在 `extra_tasks_config` 表中添加：
- `realm_id` - 主要境界ID
- `min_realm_id` - 最低境界要求
- `max_realm_id` - 最高境界要求
- `difficulty` - 难度等级（easy, normal, hard, extreme）
- `category` - 类别（basic, advanced, special）

## 设计特点

### 1. 境界递进
- 境界越高，收益越好
- 低境界项目：基础养生，简单难度
- 中境界项目：进阶养生，中等难度
- 高境界项目：高级养生，极高难度

### 2. 难度分级
- **简单（easy）**: 基础养生，低风险低收益
- **普通（normal）**: 常规养生，平衡收益
- **困难（hard）**: 挑战养生，高收益
- **极难（extreme）**: 顶级养生，极高收益

### 3. 类别分级
- **基础（basic）**: 日常养生，适合所有人
- **进阶（advanced）**: 修炼养生，需要一定基础
- **特殊（special）**: 特殊养生，独特效果

### 4. 收益递增
- 寿命收益：300秒 → 36000秒（10小时）
- 功德收益：1 → 50
- 碎片收益：0 → 20
