# 境界管理系统

## 概述

境界管理系统是整个修炼体系的核心基础，定义了修炼者从凡人到永恒的完整成长路径。系统包含5大境界，共20个小境界，每个境界都有独特的寿命上限、突破条件和核心逻辑。

## 数据库结构

### realms 表
存储所有境界的配置信息：
- `id`: 境界ID (1-20)
- `name`: 境界名称（胎息、定脉、洗髓等）
- `major_realm`: 大境界编号 (1-5)
- `sub_realm`: 小境界编号
- `major_realm_name`: 大境界名称
- `lifespan_max`: 寿命上限（秒）
- `breakthrough_age_min/max`: 建议突破年龄范围
- `description`: 境界描述
- `core_logic`: 核心逻辑说明
- `cultivation_span_min/max`: 修炼跨度范围
- `sort_order`: 排序

### user_realms 表
记录用户当前境界：
- `user_id`: 用户ID
- `current_realm_id`: 当前境界ID
- `breakthrough_count`: 突破次数
- `last_breakthrough_at`: 最后突破时间

### realm_breakthrough_logs 表
记录境界突破历史：
- `user_id`: 用户ID
- `from_realm_id`: 突破前境界
- `to_realm_id`: 突破后境界
- `breakthrough_at`: 突破时间
- `age_at_breakthrough`: 突破时年龄
- `merit_cost`: 消耗功德
- `success`: 是否成功

## 五大境界体系

### 1. 凡蜕期：百岁之劫 (1-5境)

| 二境 | 定脉 | 120岁 | 6-15岁 | 疏通经络 |
| 三境 | 洗髓 | 150岁 | 16-30岁 | 排除凡胎杂质 |

| 五境 | 玉骨 | 300岁 | 61-100岁 | 骨骼结晶化 |

| 境界 | 名称 | 寿命上限 | 修炼跨度 | 核心逻辑 |

| 境界 | 名称 | 寿命上限 | 境界说明 |

## API 接口

### 用户接口
- `GET /api/realms/list` - 获取所有境界列表
- `GET /api/realms/current` - 获取用户当前境界
- `GET /api/realms/next` - 获取下一个境界信息
- `POST /api/realms/breakthrough` - 境界突破
- `GET /api/realms/history` - 获取突破历史

### 管理员接口
- `GET /api/admin/realms` - 获取所有境界（管理）
- `PUT /api/admin/realms/:id` - 更新境界配置
- `GET /api/admin/realms/stats` - 获取境界统计

## 突破机制

### 突破条件
1. 功德要求：境界ID × 100（例如：突破到二境需要200功德）
2. 不能处于弥留期
3. 必须按顺序突破，不能跳级

### 突破奖励
- 寿命上限提升
- 解锁更高级的功法、丹药、历练项目
- 获得境界称号

### 突破记录
系统会记录每次突破的详细信息：
- 突破时间
- 突破时年龄
- 消耗的功德
- 从哪个境界突破到哪个境界

## 前端页面

### 管理后台 - 境界管理
路径：`/admin/realms`

功能：
- 查看所有境界配置
- 按大境界分组展示
- 查看每个境界的用户数量
- 编辑境界参数（寿命上限、突破年龄、描述等）
- 实时统计数据展示

界面特点：
- 可折叠的大境界分组
- 卡片式境界展示
- 实时用户统计
- 赛博朋克+道教融合风格

## 与其他系统的关联

境界系统是整个游戏的基础，后续所有模块都需要与境界关联：

### 待实现的关联
1. **丹药系统**：不同境界可使用不同丹药
2. **历练系统**：历练项目根据境界解锁
3. **天劫系统**：天劫难度随境界提升
4. **功法系统**：功法需要特定境界才能修炼
5. **装备系统**：装备有境界要求
6. **技能系统**：技能随境界解锁

## 数据迁移

运行迁移文件：
```bash
# 本地开发
wrangler d1 migrations apply DB --local

# 生产环境
wrangler d1 migrations apply webapp-production --remote
```

迁移文件会自动：
1. 创建境界相关表
2. 插入20个境界的完整数据
3. 为现有用户初始化境界（默认胎息境）

## 未来扩展

1. **境界瓶颈**：某些境界需要完成特殊任务才能突破
2. **境界回退**：失败的突破可能导致境界倒退
3. **境界加成**：不同境界提供不同的属性加成
4. **境界技能**：每个境界解锁专属技能
5. **境界称号**：达到特定境界获得特殊称号
6. **境界排行榜**：展示各境界的顶尖修炼者
