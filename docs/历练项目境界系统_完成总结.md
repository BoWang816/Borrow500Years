# 历练项目境界系统重构 - 完成总结

## 概述
将历练项目（explore loot）与境界系统关联，不同境界有不同的历练项目，难度和收益与境界相对应。

## 完成时间
2026年5月14日

## 数据库变更

### 新增字段
在 `explore_loot_config` 表中添加：
- `realm_id` - 主要境界ID
- `min_realm_id` - 最低境界要求
- `max_realm_id` - 最高境界要求
- `difficulty` - 难度等级（easy, normal, hard, extreme）
- `category` - 品质等级（common, rare, epic, legendary）

## 设计特点

### 1. 境界递进
- 境界越高，收益越好
- 低境界项目：基础收益，简单难度
- 中境界项目：中等收益，中等难度
- 高境界项目：高额收益，极高难度

### 2. 难度分级
- **简单（easy）**: 基础历练，低风险低收益
- **普通（normal）**: 常规历练，平衡收益
- **困难（hard）**: 挑战历练，高收益
- **极难（extreme）**: 顶级历练，极高收益

### 3. 品质分级
- **普通（common）**: 基础品质，常见掉落
- **稀有（rare）**: 稀有品质，较好收益
- **史诗（epic）**: 史诗品质，优秀收益
- **传说（legendary）**: 传说品质，顶级收益

### 4. 收益递增
- 寿命收益：0秒 → 302400秒（84小时）
- 功德收益：0 → 400
- 碎片收益：0 → 35
