# 数据库迁移策略

## 问题
SQLite不支持DROP COLUMN，而我们需要将字段从 `*_sec` 重命名为 `*_years`。

## 解决方案

### 方案1：代码层面转换（推荐）
在代码中进行单位转换，不修改数据库字段名：
- 数据库保持 `initial_life_sec`, `bonus_sec`, `total_gained_sec`
- 代码读取时除以 31557600 转换为年
- 代码写入时乘以 31557600 转换为秒
- 优点：不需要数据库迁移，向后兼容
- 缺点：代码中需要处理转换逻辑

### 方案2：创建新表并迁移（复杂）
- 创建新表结构
- 复制并转换数据
- 删除旧表
- 重命名新表
- 优点：数据库结构清晰
- 缺点：复杂，可能丢失数据

### 方案3：添加新字段，保留旧字段（当前采用）
- 添加新的 `*_years` 字段
- 转换现有数据到新字段
- 代码使用新字段
- 旧字段保留但不使用
- 优点：安全，可回滚
- 缺点：数据库有冗余字段
