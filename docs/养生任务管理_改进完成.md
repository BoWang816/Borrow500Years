# 养生任务管理 - 改进完成

## 改进内容

### ✅ 1. 境界关联显示
**之前：** 显示数字ID（如"境界范围: 1-5"）  
**现在：** 显示实际境界名称（如"胎息境 - 玉骨境"）

**改进点：**
- 任务列表中显示境界名称而不是ID
- 更直观，更易理解
- 自动从境界管理系统获取数据

### ✅ 2. 境界选择器
**之前：** 手动输入数字（1-20）  
**现在：** 下拉选择境界名称

**改进点：**
- 创建/编辑任务时使用下拉框
- 显示所有可用境界
- 避免输入错误的境界ID
- 更好的用户体验

### ✅ 3. 搜索功能
**新增功能：** 实时搜索任务

**支持搜索：**
- 任务名称（如"子午流注"）
- 任务键名（如"ziwu"）
- 任务描述（如"早睡"）

**特点：**
- 实时搜索，无需点击按钮
- 大小写不敏感
- 支持部分匹配

### ✅ 4. 境界过滤
**新增功能：** 按境界过滤任务

**使用场景：**
- 查看某个境界有哪些任务
- 验证任务配置是否正确
- 快速定位境界特定任务

**示例：**
- 选择"胎息境" → 显示8个任务
- 选择"聚灵境" → 显示2个任务

### ✅ 5. 统计信息
**新增功能：** 显示过滤结果统计

**显示内容：**
- "显示 X / Y 个任务"
- X = 过滤后的任务数
- Y = 总任务数

**实时更新：**
- 搜索时更新
- 过滤时更新
- 清除筛选时更新

### ✅ 6. 清除筛选
**新增功能：** 一键清除所有筛选条件

**特点：**
- 只在有筛选条件时显示
- 一键恢复显示所有任务
- 红色主题，醒目易见

### ✅ 7. 扩展任务搜索
**新增功能：** 扩展修炼项目也支持搜索

**功能：**
- 搜索项目名称、键名、描述
- 实时搜索
- 统计信息显示

## 技术细节

### 数据流
```
1. 页面加载 → loadRealms() → 获取境界列表
2. 用户搜索 → searchQuery变化 → filteredWellnessTasks重新计算
3. 用户过滤 → filterRealmId变化 → filteredWellnessTasks重新计算
4. 显示结果 → 使用filteredWellnessTasks
```

### 关键函数
```typescript
// 获取境界名称
getRealmName(realmId: number): string

// 获取境界范围描述
getRealmRangeDesc(minRealmId: number, maxRealmId: number): string

// 过滤任务
filteredWellnessTasks: ComputedRef<Task[]>

// 清除筛选
clearFilters(): void
```

### API调用
```typescript
// 获取境界列表
GET /api/realms/list
返回: { realms: Array<{id, name, ...}> }

// 获取养生任务
GET /api/admin/wellness-tasks
返回: { tasks: Array<{...}> }
```
