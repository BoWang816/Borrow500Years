# 如何查看养生任务境界系统的变化

## 问题诊断

如果你看不到页面变化，可能是以下原因：

### 1. 浏览器缓存问题
**解决方法：**
- 按 `Ctrl+Shift+R` (Windows/Linux) 或 `Cmd+Shift+R` (Mac) 强制刷新
- 或者打开浏览器开发者工具 (F12)，右键点击刷新按钮，选择"清空缓存并硬性重新加载"

### 2. 需要重新登录
**解决方法：**
- 退出登录后重新登录
- 这样会重新加载用户的境界信息

### 3. 开发服务器需要重启
**解决方法：**
```bash
# 停止当前服务器 (Ctrl+C)
# 重新启动
npm run dev
```

## 如何验证系统是否工作

### 方法1：使用测试页面
1. 打开浏览器访问 `http://localhost:5173`
2. 登录系统
3. 在新标签页打开 `test-wellness-api.html` 文件
4. 点击"加载养生任务"按钮
5. 查看返回的任务列表和当前境界ID

### 方法2：查看浏览器控制台
1. 打开浏览器开发者工具 (F12)
2. 切换到 Console 标签
3. 刷新页面或进入修炼大道页面
4. 查看控制台输出：
   ```
   Wellness tasks loaded: {tasks: Array(8), currentRealmId: 1}
   Current realm ID: 1
   Tasks count: 8
   ```

### 方法3：检查网络请求
1. 打开浏览器开发者工具 (F12)
2. 切换到 Network 标签
3. 刷新页面
4. 找到 `wellness/config` 请求
5. 查看响应内容，应该包含：
   ```json
   {
     "tasks": [...],
     "currentRealmId": 1
   }
   ```

### 方法4：直接查看数据库
```bash
sqlite3 .wrangler/state/v3/d1/miniflare-D1DatabaseObject/*.sqlite \
  "SELECT task_key, name, min_realm_id, max_realm_id FROM wellness_tasks_config WHERE is_active = 1 ORDER BY sort_order;"
```

## 常见问题

### Q: 我看到的任务数量不对
A: 检查你的当前境界。不同境界看到的任务数量不同。

### Q: 任务按钮点击没反应
A: 
1. 检查浏览器控制台是否有错误
2. 确认任务的task_key与后端匹配
3. 检查是否已经完成过该任务（今日）

### Q: 后台管理页面看不到境界范围
A: 
1. 强制刷新浏览器 (Ctrl+Shift+R)
2. 检查是否有CSS加载错误

### Q: 如何测试不同境界的任务
A: 可以通过修改数据库中用户的bonus_sec来模拟不同境界：
```sql
-- 设置为境界6（需要约5年的bonus_sec）
UPDATE users SET bonus_sec = 157680000 WHERE username = 'admin';
```

## 技术细节

### API端点
- `GET /api/tasks/wellness/config` - 获取当前境界的养生任务
- `POST /api/tasks/:taskKey` - 完成指定任务

### 数据库表
- `wellness_tasks_config` - 养生任务配置
  - `realm_id` - 任务所属境界
  - `min_realm_id` - 最小境界要求
  - `max_realm_id` - 最大境界要求
- `daily_tasks` - 每日任务完成记录
  - `completed_wellness_tasks` - JSON字段，记录境界特定任务完成状态

### 境界计算
用户境界通过以下公式计算：
```
总年龄（秒） = (当前时间 - start_timestamp) + bonus_sec
境界 = getRealmByAge(总年龄)
```
