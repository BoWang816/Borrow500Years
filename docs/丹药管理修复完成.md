## 使用说明

### 查看丹药管理
1. 启动开发服务器：`npm run dev`
2. 登录管理后台
3. 访问：`/admin/potions-config`

### 搜索和过滤
- **搜索**：在搜索框输入丹药名称、ID或描述
- **境界过滤**：选择境界，显示该境界可用的丹药
- **稀有度过滤**：选择稀有度等级
- **类别过滤**：选择丹药类别
- **清除筛选**：点击"清除筛选"按钮

### 创建/编辑丹药
1. 点击"新建丹药"按钮
2. 填写丹药信息
3. 选择境界ID、最小/最大境界
4. 选择稀有度和类别
5. 点击"创建"或"保存"

## 数据重置（如需要）
