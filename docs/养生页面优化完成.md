# 养生页面优化完成

## 优化概述

对 `/cultivation` 养生页面进行了全面优化，使其完全基于后台管理数据动态渲染，提升用户体验和可维护性。

## 主要改进

### 1. 任务分组显示 📊

**之前：** 所有任务混在一起显示  
**现在：** 按类型分组显示

#### 分组类型
- **基础修炼** - realm_requirement = 'basic'
- **境界专属修炼** - realm_requirement = 'mortal' 或 'advanced'
- **挑战修炼** - realm_requirement = 'challenge'

#### 分组特点
- 每组显示任务数量
- 独立的标题和图标
- 清晰的视觉分隔

### 2. 加载状态 ⏳

**新增功能：** 页面加载时显示加载动画

**特点：**
- 旋转的金色加载圈
- "加载养生任务中..."提示文字
- 避免空白页面闪烁

### 3. 任务完成状态 ✓

**新增功能：** 显示任务是否已完成

**视觉效果：**
- 已完成任务半透明显示
- 右上角绿色✓标记
- 按钮显示"已完成"并禁用
- 整体变暗效果

### 4. 动态输入组件 🎛️

**改进：** 根据任务的 `input_config` 动态渲染输入组件

#### 支持的输入类型

**滑块输入 (slider)**
```json
{
  "type": "slider",
  "min": 0,
  "max": 50000,
  "step": 500,
  "unit": "步"
}
```
- 用于步数输入
- 显示当前数值和单位
- 可配置范围和步长

**计数器输入 (counter)**
```json
{
  "type": "counter",
  "max": 8,
  "rewardPerUnit": 300
}
```
- 用于水杯计数
- 显示填充状态
- 视觉反馈

### 5. 改进的进度显示 📈

**早起挑战进度条：**
- 渐变色进度条（金色→青色）
- 闪光动画效果
- 居中显示进度文字
- 更直观的视觉反馈

### 6. 扩展任务优化 📜

**改进：**
- 默认显示前6个任务
- "显示全部"按钮展开
- 仅在凡蜕期（境界1-5）显示
- 更好的空间利用

### 7. 响应式设计 📱

**优化：**
- 移动端单列显示
- 平板端双列显示
- 桌面端三列显示
- 自适应字体大小

## 技术实现

### 任务分组
```typescript
const basicTasks = computed(() => 
  wellnessTasks.value.filter(t => t.realm_requirement === 'basic')
)

const realmSpecificTasks = computed(() => 
  wellnessTasks.value.filter(t => 
    t.realm_requirement === 'mortal' || 
    t.realm_requirement === 'advanced'
  )
)

const challengeTasks = computed(() => 
  wellnessTasks.value.filter(t => t.realm_requirement === 'challenge')
)
```

### 完成状态追踪
```typescript
const completedTasks = ref<Set<string>>(new Set())

function isTaskCompleted(taskKey: string): boolean {
  return completedTasks.value.has(taskKey)
}

// 完成任务后添加到集合
async function doTask(taskKey: string) {
  // ... 执行任务
  completedTasks.value.add(taskKey)
}
```

### 动态输入组件
```typescript
function getInputComponent(task: any) {
  if (!task.input_config) return null
  
  const config = JSON.parse(task.input_config)
  
  if (config.type === 'slider') {
    return h('div', { class: 'step-input' }, [
      h('input', { type: 'range', ... }),
      h('div', { class: 'step-num' }, ...)
    ])
  }
  
  if (config.type === 'counter') {
    return h('div', { class: 'water-cups' }, ...)
  }
}
```

### 加载状态
```typescript
const loadingTasks = ref(true)

async function loadWellnessTasks() {
  loadingTasks.value = true
  try {
    const res = await api('/tasks/wellness/config')
    wellnessTasks.value = res.tasks || []
  } finally {
    loadingTasks.value = false
  }
}
```
