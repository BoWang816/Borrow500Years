## ✅ 完成情况

### 1. 核心架构 ✅

**实施方案：代码层转换**
- 数据库保持原有字段名（`*_sec`）和秒单位
- 代码层使用年为单位进行所有计算
- 通过转换函数实现无缝转换

**转换函数（lib.ts）**
```typescript
export function secsToYears(secs: number): number {
  return secs / SEC_PER_YEAR;  // SEC_PER_YEAR = 31557600
}

export function yearsToSecs(years: number): number {
  return years * SEC_PER_YEAR;
}
```

## 📊 技术细节

### 数据流

```
用户输入（年）
    ↓
前端发送（年）
    ↓
后端接收（年）
    ↓
yearsToSecs() 转换
    ↓
数据库存储（秒）
    ↓
数据库读取（秒）
    ↓
secsToYears() 转换
    ↓
后端计算（年）
    ↓
API响应（年）
    ↓
前端显示（年）
```

### 字段映射

#### 数据库（秒）→ API响应（年）
- `initial_life_sec` → `initialLifeYears`
- `bonus_sec` → `bonusYears`
- `total_gained_sec` → `totalGainedYears`
- 计算得到 → `lifeYears`

#### 配置表
- `life_reward` (秒) → 代码中转换为年
- `instant_life` (秒) → 代码中转换为年
- `cost_life` (秒) → 代码中转换为年
- `reward_life` (秒) → 代码中转换为年

### 显示格式

`formatLife()` 函数智能显示：
- ≥ 1年: "X.XX 年"
- < 1年 ≥ 1天: "X 天"
- < 1天 ≥ 1小时: "X 小时"
- < 1小时: "X 分钟"
