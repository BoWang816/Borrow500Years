# 丹药系统境界重构完成

## 重构概述

将丹药系统与境界系统深度关联，每个境界都有专属的丹药，境界越高丹药功效越强，使用成本也越高。

## 数据库改进

### 新增字段
```sql
ALTER TABLE potions_config ADD COLUMN realm_id INTEGER DEFAULT 1;
ALTER TABLE potions_config ADD COLUMN min_realm_id INTEGER DEFAULT 1;
ALTER TABLE potions_config ADD COLUMN max_realm_id INTEGER DEFAULT 20;
ALTER TABLE potions_config ADD COLUMN rarity TEXT DEFAULT 'common';
ALTER TABLE potions_config ADD COLUMN category TEXT DEFAULT 'recovery';
```

### 字段说明
- **realm_id**: 丹药所属境界
- **min_realm_id**: 最低使用境界
- **max_realm_id**: 最高使用境界
- **rarity**: 稀有度（common/rare/epic/legendary）
- **category**: 类别（recovery恢复/buff增益/special特殊）

## 稀有度系统

### Common（普通）
- 基础丹药
- 效果一般
- 价格适中

### Rare（稀有）
- 进阶丹药
- 效果较好
- 价格较高

### Epic（史诗）
- 高级丹药
- 效果优秀
- 价格昂贵

### Legendary（传说）
- 顶级丹药
- 效果卓越
- 价格极高

## 类别系统

### Recovery（恢复类）
- 主要增加即时寿命
- 快速恢复生命值
- 适合紧急情况

### Buff（增益类）
- 主要降低衰减率
- 持续时间较长
- 适合长期使用

### Special（特殊类）
- 特殊效果
- 独特机制
- 稀有珍贵

## 设计理念

### 平衡性
- 高境界丹药效果强但成本高
- 低境界丹药性价比高
- 稀有度影响效果上限

### 渐进性
- 每个境界至少5个丹药
- 效果递增合理
- 成本递增合理

### 多样性
- 恢复类和增益类并存
- 不同稀有度选择
- 满足不同需求
