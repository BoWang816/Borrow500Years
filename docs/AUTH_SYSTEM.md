# 登录注册系统说明

## 概述

全新的登录注册系统，将账号注册和命盘开启合并到一个页面，实现天命测算算法。

## 功能特点

### 1. 统一的认证界面
- **登录模式**：输入道号和心法口诀即可登录
- **注册模式**：填写基本信息，实时显示天命测算结果

### 2. 天命测算算法

#### 输入校验
- 年龄：1-100 岁
- 身高：100-250 cm
- 体重：30-200 kg

#### 计算流程

**步骤 1：计算 BMI**
```
BMI = 体重(kg) / (身高(m))²
```

**步骤 2：计算健康减损系数 δ**
- 若 `BMI < 18.5` 或 `BMI > 28`：
  ```
  δ = 1.0 - (|BMI - 23.2| × 0.02)
  δ = max(δ, 0.5)  // 最低不低于 0.5
  ```
- 若 `18.5 ≤ BMI ≤ 24`：
  ```
  δ = 1.0  // 完美健康
  ```
- 若 `24 < BMI ≤ 28`：
  ```
  δ = 1.0 - (|BMI - 23.2| × 0.02)
  δ = max(δ, 0.5)
  ```

**步骤 3：计算初始总寿元**
```
T_max = 100年 × δ
```

**步骤 4：计算剩余可用寿元**
```
T_now = (T_max - 当前年龄) × 31,536,000 秒
```

**步骤 5：异常处理（一线生机）**
- 若 `T_now ≤ 0`：
  - 初始寿命：3600 秒（1小时）
  - 初始功德：100
  - 状态：逆天改命

### 3. 根骨评级

根据健康系数 δ 评定根骨品质：

| δ 范围 | 评级 | 颜色 |
|--------|------|------|
| ≥ 0.95 | 上品 | 紫色 |
| ≥ 0.85 | 中品 | 青色 |
| ≥ 0.70 | 凡品 | 金色 |
| < 0.70 | 下品 | 橙色 |
| 一线生机 | 逆命 | 红色 |

### 4. 实时预览

注册时实时显示：
- 天命寿元（总寿命）
- 剩余寿元（可用寿命）
- 根骨评级
- 一线生机提示（如果触发）

## 技术实现

### 前端
- **文件**：`src/client/components/AuthModal.vue`
- **特点**：
  - 使用 Vue 3 Composition API
  - 响应式计算天命测算结果
  - 表单验证和错误处理
  - 优雅的动画和过渡效果

### 后端
- **文件**：`src/server/api/modules/profile.ts`
- **改进**：
  - 支持接收前端计算的初始寿命
  - 支持设置初始功德
  - 记录一线生机状态

### 数据流

```
用户输入 → 前端计算天命 → 注册账号 → 开启命盘 → 跳转仪表盘
```

## 使用示例

### 正常情况
```
年龄：25 岁
身高：170 cm
体重：65 kg

BMI = 65 / (1.7)² = 22.5
δ = 1.0 (完美健康)
T_max = 100 × 1.0 = 100 年
T_now = (100 - 25) × 31,536,000 = 75 年
```

### 一线生机
```
年龄：95 岁
身高：160 cm
体重：45 kg

BMI = 45 / (1.6)² = 17.6
δ = 1.0 - (|17.6 - 23.2| × 0.02) = 0.888
T_max = 100 × 0.888 = 88.8 年
T_now = 88.8 - 95 = -6.2 年 ≤ 0

触发一线生机：
- 初始寿命：3600 秒
- 初始功德：100
- 提示：逆天改命
```
