# 修仙丹药体系

## 概述

全新的修仙丹药体系已经替换了原有的现代保健品系统，现在包含两大类修仙丹药和基础修仙丹药。

## 丹药分类

### A. 逆转造化类（对应原物理类）

这类丹药能够逆转自然规律，改变物理法则：

#### ⚡ 无距砂
- **消耗**: 100 功德
- **效果**: 持续6小时，衰减减少15%
- **描述**: 吞服后周身三尺无视距离之限，以此物抹在剑上，剑出即中，无视虚空

#### 🏔️ 镇狱沉汞
- **消耗**: 120 功德
- **效果**: 持续8小时，衰减减少25%
- **描述**: 极沉之水，入腹后身体重如山岳根基，足踏大地则万法不动

#### 🔄 反朔散
- **消耗**: 150 功德
- **效果**: 持续4小时，衰减减少20%
- **描述**: 受击瞬间，伤势反向转嫁于出招者，称之为"因果倒悬"

#### 🌫️ 息劫灰
- **消耗**: 200 功德
- **效果**: 持续12小时，衰减减少35%
- **描述**: 采自寂灭星辰的余灰，服下后周身气机彻底静止，连时间也无法在其身上留下痕迹

### B. 禁忌玄理类（对应原逻辑类）

#### ☯️ 两仪错位丹

- **描述**: 使服用者处于"似在非在"之间，肉眼可见，神识却空无一物

#### 🌊 遗世忘川水
- **消耗**: 250 功德
- **效果**: 持续3小时，衰减减少40%
- **描述**: 洗去天道对自身的"注视"，服下后短时间内不沾因果，可躲避任何天劫探测

#### ✨ 溯源金液
- **消耗**: 300 功德
- **效果**: 直接增加24小时寿命
- **描述**: 强行将身体状态拨回至全盛之时，如同枯木逢春，逆转寿元

#### 👁️ 窥天盲片
- **消耗**: 220 功德
- **效果**: 持续24小时，衰减减少10%，功德获取效率+150%
- **描述**: 借得一丝天道视角，虽只有一瞬，却能看破世间万物运行的脉络

## 丹药效果说明

### 效果类型

1. **即时寿命增加**: 服用后立即增加指定秒数的寿命
2. **持续衰减减少**: 在指定时间内降低生命衰减率
3. **功德加成**: 在指定时间内提升功德获取效率

### 消耗类型

- **功德**: 所有丹药均消耗功德
- **复活币**: 暂未使用，为未来扩展预留

## 管理功能

### 管理员功能

管理员可以通过后台管理系统：

1. **查看丹药配置**: 查看所有丹药的详细配置
2. **创建新丹药**: 添加新的丹药配置
3. **编辑丹药**: 修改现有丹药的属性
4. **删除丹药**: 移除不需要的丹药
5. **启用/禁用**: 控制丹药是否可用

### 丹药属性

每个丹药包含以下属性：

- **ID**: 唯一标识符
- **名称**: 丹药名称
- **图标**: emoji 表情
- **描述**: 丹药功效描述
- **消耗**: 使用丹药需要的资源数量
- **消耗类型**: merit（功德）或 shard（复活币）
- **即时寿命**: 立即增加的寿命秒数
- **持续时间**: 效果持续的秒数
- **衰减减少**: 降低的衰减率（0-1之间的小数）
- **功德加成**: 功德获取倍率（1.0表示无加成）
- **排序**: 显示顺序
- **状态**: 是否启用

## 数据库结构

丹药配置存储在 `potions_config` 表中：

```sql
CREATE TABLE potions_config (
  id TEXT PRIMARY KEY,
  emoji TEXT,
  name TEXT NOT NULL,
  desc TEXT,
  cost INTEGER DEFAULT 0,
  type TEXT DEFAULT 'merit',
  instant_life INTEGER DEFAULT 0,
  instant_merit INTEGER DEFAULT 0,
  dur INTEGER DEFAULT 0,
  dur_decay_reduction REAL DEFAULT 0,
  dur_merit_boost REAL DEFAULT 0,
  sort_order INTEGER DEFAULT 0,
  is_active BOOLEAN DEFAULT 1
);
```

## 使用方式

1. 用户在游戏中通过各种方式获得功德
2. 在丹药界面选择想要的丹药
3. 消耗对应的功德购买丹药
4. 丹药效果立即生效或在指定时间内持续生效

## 平衡性考虑

- 高级丹药消耗更多功德，但提供更强大的效果
- 即时效果丹药适合紧急情况
- 持续效果丹药适合长期规划
- 功德加成丹药可以帮助玩家更快积累资源
