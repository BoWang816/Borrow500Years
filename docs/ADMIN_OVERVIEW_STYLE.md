# 平台概览页面赛博朋克+道教风格样式

## 设计理念

将赛博朋克的科技感与道教的神秘感融合，创造出独特的视觉体验：
- **赛博朋克元素**：霓虹色彩、渐变边框、扫描线动画、发光效果
- **道教元素**：青色（#36ffd0）代表仙气、金色（#d4af37）代表功德、粉色（#ff6b9d）代表生命力
- **色彩丰富**：多色渐变、动态光效、层次分明

## 主要特性

### 1. 统计卡片
- **渐变边框**：三色渐变（青-金-粉）动态旋转
- **悬停效果**：上浮动画 + 发光阴影
- **图标样式**：渐变文字 + 投影光晕
- **数值显示**：大号渐变字体 + 发光效果

### 2. 搜索栏
- **圆角设计**：25px圆角，更柔和
- **聚焦效果**：边框发光 + 背景变亮
- **图标位置**：右侧悬浮，青色发光

### 3. 用户列表项
- **左侧光条**：悬停时显示三色渐变竖条
- **滑动效果**：悬停时向右平移
- **信息布局**：
  - 大号头像图标（渐变色）
  - 用户名（渐变文字）
  - 真实姓名（半透明白色）
  - 状态徽章（发光边框）
  - 统计信息（胶囊样式）

### 4. 徽章样式
- **弥留状态**：粉红色渐变 + 发光边框
- **未激活**：灰色半透明
- **圆角胶囊**：12px圆角
- **大写字母**：增强科技感

### 5. 按钮效果
- **新建按钮**：
  - 青金渐变背景
  - 悬停时波纹扩散效果
  - 上浮 + 金色阴影
- **操作按钮**：
  - 继承admin-form-styles.css样式
  - 图标按钮设计

### 6. 动画效果
- **扫描线**：卡片顶部水平扫描动画（3秒循环）
- **边框发光**：悬停时色相旋转动画（2秒循环）
- **波纹效果**：按钮点击时从中心扩散
- **平滑过渡**：所有交互都有0.3s过渡

## 色彩方案

### 主色调
- **青色（仙气）**：#36ffd0 - 主要强调色
- **金色（功德）**：#d4af37 - 次要强调色
- **粉色（生命）**：#ff6b9d - 警告/危险色

### 背景色
- **深色基底**：rgba(13, 2, 8, 0.95) - 深紫黑色
- **渐变背景**：135度线性渐变，从深紫到深红
- **卡片背景**：青金渐变，3-5%透明度

### 文字色
- **主文字**：#fff - 纯白
- **次要文字**：rgba(255, 255, 255, 0.6) - 60%透明白
- **占位符**：rgba(255, 255, 255, 0.4) - 40%透明白

## 技术实现

### CSS特性
- **渐变文字**：`-webkit-background-clip: text`
- **渐变边框**：`border-image` + `linear-gradient`
- **遮罩效果**：`mask-composite` 实现镂空边框
- **滤镜效果**：`drop-shadow` + `filter: hue-rotate`
- **CSS动画**：`@keyframes` 定义循环动画

### 响应式设计
- **网格布局**：`grid-template-columns: repeat(auto-fit, minmax(220px, 1fr))`
- **弹性布局**：`display: flex` 配合 `gap`
- **自适应间距**：使用相对单位和百分比

### 性能优化
- **硬件加速**：使用 `transform` 而非 `top/left`
- **合理动画**：仅在悬停时触发复杂动画
- **CSS变量**：继承全局CSS变量（通过admin-form-styles.css）

## 视觉层次

### 第一层：统计卡片
- 最醒目的位置
- 大号图标和数字
- 强烈的发光效果

### 第二层：搜索和操作
- 功能性区域
- 中等强度的视觉效果
- 清晰的交互反馈

### 第三层：用户列表
- 内容展示区域
- 悬停时增强视觉效果
- 信息层次分明

## 道教元素体现

1. **八卦色彩**：青（木）、金（金）、粉（火）
2. **仙气缭绕**：发光效果模拟灵气
3. **符文感**：渐变边框如同法阵
4. **流动能量**：扫描线动画如同气流

## 赛博朋克元素体现

1. **霓虹灯效**：多色发光边框和文字
2. **全息投影**：半透明叠加效果
3. **数字界面**：大写字母、等宽字体感
4. **故障美学**：扫描线、色相偏移

## 使用建议

1. **保持一致性**：其他后台页面也应采用类似风格
2. **适度使用动画**：避免过度动画影响性能
3. **注意对比度**：确保文字可读性
4. **测试兼容性**：在不同浏览器测试渐变和动画效果
