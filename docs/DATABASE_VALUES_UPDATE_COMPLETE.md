## 数值设计原则

1. **境界差异明显**: 每个境界阶段的数值有10倍左右的差距
2. **符合修仙世界观**: 
   - 凡蜕期：以天为单位
   - 超凡期：以年为单位
   - 化境期：以十年为单位
   - 极境期：以百年为单位
   - 道极期：以千年为单位
3. **品质/难度差异**: 同一境界内，不同品质/难度的奖励也有明显差异
4. **游戏平衡**: 数值设计考虑了游戏进度和玩家体验

- 所有字段保持原名（`*_sec`）

- 数值：已更新为适合年单位的大数值

### 代码层
- 使用 `secsToYears()` 和 `yearsToSecs()` 进行转换
- API返回：年单位（`*Years` 字段）
- 前端输入：年单位
- 前端显示：智能格式化（年/天/小时/分钟）

### 转换函数
```typescript
// src/server/lib.ts
export const SEC_PER_YEAR = 365.25 * 86400;

export function secsToYears(secs: number): number {
  return secs / SEC_PER_YEAR;
}

export function yearsToSecs(years: number): number {
  return years * SEC_PER_YEAR;
}
```
