# 测试清单 - 年单位系统验证

## 测试目的
验证数据库数值更新后，系统各个模块是否正确显示和处理年单位的寿命数值。

## 前置条件
- ✅ 数据库迁移已执行（0026_update_lifespan_values_for_years.sql）
- ✅ 代码已更新为年单位系统
- ✅ 构建成功（npm run build）

## 启动开发服务器

```bash
# 启动本地开发服务器
npm run dev

# 或使用自定义开发服务器
node dev-server.js
```
